01 Introducción y Conceptos Clave

Este informe documenta la implementación de dos mejoras críticas de UX (Experiencia de Usuario) en el Sistema de Gestión de HIDROSYS EC.: los Estados Vacíos (Empty States) y el Detector de Modo Sin Conexión (Offline Mode). Ambas funcionalidades elevan la calidad profesional del sistema al nivel de plataformas SaaS de grandes empresas.

¿Qué es un Estado Vacío (Empty State)?

Un Estado Vacío es el diseño de interfaz que se muestra cuando una sección del sistema no tiene datos que mostrar. En lugar de dejar la pantalla en blanco (lo que genera confusión en el usuario), se presenta:

🎨

Ilustración Visual

Un ícono grande y claro que identifica el módulo y comunica el estado de forma inmediata.

📝

Mensaje Explicativo

Un texto claro que explica POR QUÉ la pantalla está vacía y qué significa eso para el usuario.

👆

Llamada a la Acción

Un botón que guía al usuario al siguiente paso lógico, eliminando la parálisis de análisis.

🎯

Diseño Contextual

Cada módulo tiene su propio color e icono, reforzando la identidad visual y la comprensión.

¿Qué es el Modo Sin Conexión (Offline Mode)?

Es un sistema de detección automática del estado de la red del usuario. Cuando el navegador pierde acceso a internet, el sistema reacciona inmediatamente para proteger los datos del usuario y evitar pérdidas de información.

CondiciónComportamiento del SistemaImpacto
🔴 Sin Internet Banner rojo en la parte superior de la página Usuario es informado al instante
🔴 Sin Internet Botones de acción deshabilitados automáticamente Se previene pérdida de datos
🟢 Con Internet Banner verde de confirmación por 3 segundos Usuario puede continuar con confianza
🟢 Con Internet Botones re-habilitados automáticamente Sistema vuelve al funcionamiento normal

02 Estados Vacíos — Diseño Visual

2.1 Estado Vacío: Agenda y Citas

Se activa en el Panel de Administrador cuando no existen citas registradas, ya sea porque el sistema es nuevo o porque los filtros aplicados no arrojan resultados. El diseño usa una paleta azul grisácea neutra para transmitir calma y la ausencia de urgencia.

2.2 Estado Vacío: Prospectos (Proyectos Grandes)

Se activa en la pestaña "Prospectos" cuando aún no se han recibido formularios de proyectos grandes. Incluye el botón especial "➕ Agregar Datos de Prueba" que permite al administrador insertar un prospecto ficticio para realizar pruebas del flujo de conversión a cliente, sin necesidad de intervención técnica. El diseño usa una paleta azul corporativo, alineada con la identidad de Hidrosys.

03 Estados Vacíos y Modo Sin Conexión

3.1 Estado Vacío: Encuestas de Satisfacción

Se activa en la pestaña "Satisfacción" cuando no hay encuestas aún. Explica proactivamente el flujo automático del sistema, educando al administrador sobre cómo se generan las encuestas. El diseño usa una paleta verde esmeralda para evocar confianza, éxito y calidad de servicio.

3.2 Detector de Modo Sin Conexión (Offline)

El sistema detecta en tiempo real la pérdida de conexión a internet y reacciona mostrando banners informativos. A continuación se muestran los dos estados del banner:

Arriba: Estado offline (banner rojo). Abajo: Estado reconectado (banner verde).

4.2 Código: Detección de Conexión (main.js)

Se utilizan los eventos nativos del navegador para detectar cambios en la red sin depender de librerías externas:

// Evento nativo del navegador: se dispara al perder Internet window.addEventListener('offline', () => { const banner = document.getElementById('offline-banner'); banner.style.display = 'block'; banner.className = 'offline-banner'; // Clase roja // Deshabilitar botones críticos para proteger datos document.querySelectorAll('.btn-primary, .btn-success') .forEach(btn => { btn.disabled = true; btn.textContent = '❌ Sin conexión'; }); }); // Evento nativo del navegador: se dispara al recuperar Internet window.addEventListener('online', () => { banner.className = 'offline-banner online'; // Clase verde setTimeout(() => { banner.style.display = 'none'; }, 3000); // Re-habilitar botones automáticamente document.querySelectorAll('.btn-primary, .btn-success') .forEach(btn => { btn.disabled = false; }); });
